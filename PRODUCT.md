# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

VitePress (Markdown pages, Node build). Chosen by the user over plain HTML.

## Users

People who know some programming but have never built an ASP.NET Core app. They read the docs while building their first project, usually with an editor and terminal open beside the browser.

## Product Purpose

An unofficial, beginner-friendly guide to ASP.NET Core, modeled on the Laravel documentation (https://laravel.com/docs): short pages, one topic each, copyable code, left sidebar, "on this page" outline. Success means a reader can go from an empty folder to a working app by following the pages in order.

## Positioning

The content is split into two self-contained tracks so a beginner never reads about a model they are not using:

- MVC: server-rendered HTML with controllers, Razor views, and forms.
- Web API: JSON APIs with Minimal APIs and API controllers.

Each track has two parts. Part 1 takes a beginner from an empty folder to a deployed app. Part 2 ("Advanced") is for mid-level readers: architecture, performance, queues, integrations, production, deeper testing.

## Capabilities and Constraints

- Targets .NET 10 (LTS) and C# 14. Code samples must compile on that version.
- Every page is short and ordered so it can be read top to bottom.
- Plain language. Explain a term the first time it appears.
- Unofficial: not affiliated with Microsoft. Links to learn.microsoft.com for depth.

## Brand Commitments

- Look and structure follow the Laravel docs (user's explicit reference).

## Evidence on Hand

No testimonials, metrics, or users. Do not invent any.

## Product Principles

1. One page, one topic, one working example.
2. Pick a track early and stay in it.
3. Show the command or the code first, explain after.
4. Prefer the default template's way of doing things over clever alternatives.
